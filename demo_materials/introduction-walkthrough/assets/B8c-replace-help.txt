Replace a control-plane node (POST /clusters/{name}/control-plane/replace)

Usage:
  umkim node replace [flags]

Flags:
      --address string    New node management address
      --cluster string    Cluster name
      --force             Force replace when old node is offline
  -h, --help              help for replace
      --hostname string   New node hostname (optional)
      --old-node string   Control-plane node name to replace (Kubernetes node name)

Global Flags:
      --api-url string    Fleet API base URL (or UMKIM_API_URL)
      --auth-url string   Auth API base URL (or UMKIM_AUTH_URL)
  -o, --output string     Output format: table, wide, json (default "table")
      --token string      Service account token (or UMKIM_TOKEN)
